# ola-ride-booking-analysis
This project provides a comprehensive analysis of Ola ride booking data using *Python (Google Colab), **SQL, and **Power BI*. It covers data cleaning, exploratory data analysis (EDA), database querying, and interactive dashboard creation to derive business insights.

### 🛠️ Technologies Used
* *Python (Google Colab):* Data Cleaning, Processing, and Initial Analysis
* *SQL:* Advanced querying for specific business questions and metrics
* *Power BI:* Interactive Data Visualization and Dashboard Building

### 📂 Project Structure
* cleaned_ride_bookings.csv: The cleaned dataset used for analysis.
* Ola_Ride_Bookings_Analytics_.ipynb: Google Colab notebook containing Python data cleaning and EDA code.
* Ola_Project_Analysis.sql: SQL script with queries analyzing ride patterns, cancellations, and revenues.
* Ola_Ride_Analytics_Project.pbix: Power BI dashboard file showing key business insights.

### 📈 Key Insights & Dashboard Features
* *Ride Volume & Status:* Tracked total bookings, successful rides, and cancellation rates.
* *Revenue Analysis:* Insights into total revenue generated by vehicle types and customer segments.
* *Cancellation Reasons:* Detailed breakdown of why rides were canceled by drivers or customers.
* *Ratings:* Analysis of driver and customer satisfaction trends.
